# CG 放这里（三张）

游戏自动检测下面三个文件，**放进去就生效，没有就跳过**（不会挡流程）。
文件名必须一致，格式 PNG。

| 文件名 | 什么时候播 | 她说的话（字幕 + 配音） |
|---|---|---|
| `lose_all.png` | **你输光**（筹码低于 100 万底注）→ 播完才弹"求情借钱 / 重新开始" | 杂鱼，要不我借你点，代价吗…… |
| `give_up.png` | **你认输**（在输光面板选"重新开始"，或求情求到一半放弃） | 杂鱼就是杂鱼，赢不过我 |
| `you_win.png` | **你把它打光**（它付不起底注，尤其被 ALL IN 清空）→ 播完弹"你把它打光了！"选择页 | 我的token……哭 |
| `poked.png` | **彩蛋**：你连戳鲸鱼娘三次（前两次普通发怒，第三次缓慢黑化 → 重力一击） | 你因为手贱，被鲸鱼娘干掉了（旁白字幕）+ 念「叫你手贱」 |

另外彩蛋还需要**两个立绘**（都在 `assets/whale/`，4 帧 × 48×57 横向排开，
`manifest.json` 里已经登记好 `angry` 与 `black`）：

- `angry.png` —— 前两次戳它时的发怒
- `black.png` —— 第三次的黑化

**没有它们彩蛋照样能玩** —— 立绘回落到 idle，但抖动、压暗、白闪、台词、音效都在。
如果外援立绘不是 48×57 的标准规格（比如是 4 倍大、带纯色底），
用 `tools/prepare_whale_extra.py` 规整一下即可。

三句台词都已经**烤成配音**（`assets/voice/xiaoyi/`），所以 CG 一出来她就会念，
不是运行时现烤、没有延迟。

## 规格

- **1280×760**（和游戏窗口一致；整屏铺满、保持比例居中，比例不符会左右留黑边）
- 建议 **16-bit 像素风**，和牌面 / 背景同一套美术
- 画面上会压三行字，**这些区域别放关键内容**：
  - 顶部 `y=42`：小标题（"你输光了 / 你认输了 / 你赢了"）
  - 下沿 `y=628`：她的台词（26px 金色）
  - 下沿 `y=672 / 702`：提示与"继续"按钮
- 播的时候会**缓慢浮现**（约 3 秒）：黑场盖上来 → 画面淡入并轻微推进（1.06→1.0）→
  小标题 → 她的台词（**台词浮现的那一刻才开口念**，声音和字幕对齐）→ 提示与按钮。
  浮现过程中**点一下是"跳过动画"**（直接落到终态），再点一下才翻页 —— 不会误触跳过整张图。
- 播放时会响一声 sting（你输用 `bust`，你赢用 `blackjack`）并停掉之前的语音
- 点一下、按任意键、或点"继续"都能翻过去

## 代码位置

- 播放层：`scripts/ui/bj_table_view.gd` 的 `CG_TABLE` / `_build_cg()` / `_show_cg()` / `_dismiss_cg()`
- 触发点：`BjGame.bankrupt`（你输光）、`BjGame.opponent_bankrupt`（它输光）、
  以及"重新开始"按钮（= 认输）
